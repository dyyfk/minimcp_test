We evaluate frozen MiniCPM-o~4.5 (9B), with \texttt{gpt-5.5} as the
escalation expert, on the full 240-query internal test set and four
external English speech-QA pools: Speech TriviaQA, Speech Web Questions,
and Speech Llama Questions from OpenAudioBench \citep{openaudiobench2025},
and SD-QA from VoiceBench \citep{faisal2021sdqa,chen2024voicebench}.
For the answer-content benchmark, the native probe is fitted on 5,221
calibration rows after excluding benchmark overlaps. Its results were rerun
with this refitted probe; per-language thresholds use the remaining
core rows' out-of-fold scores and stay fixed across pools.
Calibration details and model controls are in
Appendix~\ref{app:current-protocol}.

Each query has one sampled native session per arm: local-only,
conservative, balanced, aggressive, and always-escalate.
We report \emph{answer-content accuracy}, scored from generated local
text or intended relay text. The random reference is the analytical
mixture $A_{\rm mix}(r)=(1-r)A_{\rm local}+rA_{\rm always}$ at the
gate's realized call rate $r$. Both model families use all 240
Internal query IDs: chat (60), factual QA (40), knowledge (60), math (60),
and SimpleQA traps (20). Every query has unit weight in accuracy and
call-rate calculations. Table~\ref{tab:live} gives the per-tier results
and uncertainty intervals on this full test set.
External averages weight the four QA pools equally.
\paragraph{Metric sources and timing endpoint.}
All tables and trade-off figures use the retained judged benchmark for
accuracy and escalation rate, and the complete \texttt{ttfa-v3} run
for latency on the same query IDs. This timing run contains 5,950
recorded sessions across five pools and five policies; TTFA comes
directly from session timestamps. We compare the resulting per-policy
summaries. Appendix~\ref{app:metric-sources} gives the input and recording
details for each metric. Server TTFA measures the wait
from scheduled input end until the first answer PCM block is ready;
audio ready earlier incurs zero wait. Candidate and stall audio are excluded;
client playback is unmeasured.
Appendix~\ref{app:setup-details} provides the model, probe-fitting,
and answer-judging configurations used in these experiments.
