\subsection{From a failure score to an answer-onset decision}
\label{sec:system}
For native serving, we concatenate the last tail state, the mean of
the tail states, and the mean input state at L22 into
$\phi(x)\in\mathbb{R}^{12288}$. A logistic probe gives
\begin{equation}
 s(x)=\sigma\!\left(w^\top\phi(x)+b\right),\qquad
 d(x)=\mathbf{1}\{s(x)\geq\tau_{\ell}\}\,
       \mathbf{1}\{a(x)\geq\tau_a\},
 \label{eq:gate}
\end{equation}
where $a(x)$ is a separately fitted dialogue-act score that filters
floor-management turns, and $\tau_{\ell}$ is a language-specific
failure threshold. Calibration-score quantiles define three nominal
budgets (15/30/50\%); realized rates can differ on a new pool.
The model weights stay frozen, but both heads require fitting.

The native capture occurs when a generation call first returns a
listen-to-speak transition. It can include the first generated text
unit, so we call it \emph{answer onset}. This differs from the earlier
turn-based prefill read, whose measured P50 availability was 20\,ms
for text and 45\,ms for audio on an H100. A separate turn-end replay
reported about 30\,ms (Appendices~\ref{app:gatedetail}
and~\ref{app:livedetail}); those measurements are not native-path
end-to-end latency. Later native reads can improve reasoning-failure
prediction, at the cost of waiting for answer chunks
(Appendix~\ref{app:readtime}).
